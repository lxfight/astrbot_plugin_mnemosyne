# 管理面板

Mnemosyne 通过 AstrBot Dashboard 提供长期记忆管理页面。面板与插件共用同一套向量数据库适配器，因此 Chroma、Milvus、Qdrant 和 Weaviate 的管理入口一致。

## 打开面板

1. 使用 AstrBot 管理员账号登录 Dashboard。
2. 进入 **Alkaid**。
3. 打开 **长期记忆** 页面。

不同 AstrBot 版本的菜单名称可能略有差异，但入口始终位于插件管理区域。面板不单独监听端口，也不维护独立账号体系。

## 页面功能

| 页面 | 用途 |
| --- | --- |
| 系统脉搏 | 查看系统状态、记忆总数、活跃会话、数据库连接和记忆拓扑。 |
| 记忆工作台 | 按会话、人格、时间和关键词检索记忆，查看详情并删除记录。 |
| 会话图谱 | 浏览会话记忆数量与时间范围，清理整个会话。 |
| 统计信号 | 查看每日新增、会话分布和总量趋势。 |
| 运行配置 | 查看当前运行时配置，确认数据库、模型和检索参数。 |

## 编辑记忆

打开记忆检查器后，可以修改记忆正文。保存时 Mnemosyne 会重新生成 Embedding，再写回向量数据库。

- 正文上限为 4096 个字符，与集合字段长度一致。
- 修改内容会改变后续检索结果，不应只修正错别字而不评估语义变化。
- 删除记录、删除会话和批量操作都会在页面内请求确认，确认后不可恢复。

## 性能指标

面板展示最近查询的分阶段延迟，包括 Embedding、向量搜索、后处理、记忆注入、数据库操作和完整 RAG 查询。每项指标提供 P50、P95 和 P99。

指标只保存在当前进程内，默认最多保留 1000 个样本，重启 AstrBot 后清零。需要定位慢请求时，先比较各阶段 P95，再调整 Provider、数据库或检索参数。详细阈值见[性能调优](/guide/performance)。

## 缓存与刷新

记忆统计、会话列表和资源统计使用 10 秒短期缓存，避免面板刷新时重复扫描大量记录。删除或更新记忆后，相关缓存会立即失效。

## 安全建议

- 管理面板继承 AstrBot 的管理员权限，不要向公网匿名开放 Dashboard。
- 记忆内容可能包含个人偏好、会话片段和业务信息，导出文件应按敏感数据处理。
- 删除操作不可恢复。批量清理前优先使用命令的预览模式或先导出备份。
